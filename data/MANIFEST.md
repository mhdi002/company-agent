## Notes

* **fineweb-edu** — Educational web text filtered by an edu classifier; 10BT sample.
* **pg19** — Project Gutenberg books published before 1919.
* **edgar-corpus** — 10-K 'Item 1. Business' and MD&A sections: company self-descriptions.
* **cordis-h2020** — EU-funded project objectives: proposal-style text.
* **nsf-awards** — Funded grant abstracts (project proposals).
* **nih-exporter** — NIH project abstracts.
* **ted-tenders** — Public tender / RFP notices (EU TED).
* **arxiv-abstracts** — Technical report abstracts.
* **big-patent** — Patent abstracts: technical problem/solution language.
* **glaive-function-calling-v2** — Function-calling dialogues (format exposure only).
* **hermes-function-calling-v1** — Structured tool-calling conversations.
* **synthetic-srlm-traces** — Programmatic SRLM program traces with calibrated confidence (Phase 4).
